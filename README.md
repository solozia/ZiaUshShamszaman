# Dr Zia Ush Shamszaman

A custom static website for GitHub Pages.

## Publish

1. Rename your GitHub repository to `solozia.github.io`.
2. Upload **the contents of this folder** to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site should appear at `https://solozia.github.io`.

## Before publishing

- Replace the photograph placeholder. Put a professional photo at `assets/images/profile.jpg` and update the homepage markup to display it.
- Complete the selected-publications page. Placeholders are intentional; no bibliographic details were invented.
- Replace the Google Scholar placeholder button (`href="#"`) with your Scholar URL.
- Review project descriptions for SafeSCMS and iShield and add one-sentence technical summaries/outcomes.
- Add current editorial/special-session details on the Service page.
- Add evidence and links for media/outreach items on the Impact page.
- Add a current CV PDF under `assets/files/` if you want a downloadable CV link.

## Structure

- `index.html` — Home
- `research.html` — Research
- `publications.html` — Publications
- `projects.html` — Projects
- `teaching.html` — Teaching & supervision
- `leadership.html` — Leadership
- `service.html` — Academic & professional service
- `impact.html` — Impact, media & outreach
- `contact.html` — Contact
- `assets/css/style.css` — Site design
- `assets/js/site.js` — Mobile navigation

No template or build system is required.
